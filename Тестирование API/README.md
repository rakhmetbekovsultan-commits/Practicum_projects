Проект автоматизированного тестирования API: Яндекс.Самокат

Описание проекта
Проект представляет собой набор автоматизированных тестов для проверки ключевых ручек (API endpoints) бэкенд-сервиса «Яндекс.Самокат». Тестирование направлено на проверку корректности работы функционала, обработки успешных сценариев, а также валидацию ошибок при передаче некорректных или неполных данных.

Стек технологий
Язык программирования: Python

Фреймворк для тестирования: pytest

HTTP-клиент: requests

Генерация отчётов: Allure Report

Система контроля версий: Git / GitHub

1. Создание курьера (/api/v1/courier)
Проверена возможность успешного создания нового курьера (возвращается код 201 Created и тело ответа {"ok": true}).

Проверена валидация обязательных полей: если передать неполный набор данных, система возвращает ошибку.

Проверена уникальность: попытка создания двух одинаковых курьеров или пользователя с уже существующим логином приводит к ошибке.

2. Логин курьера (/api/v1/courier/login)
Проверен успешный процесс авторизации существующего курьера (успешный запрос возвращает уникальный id курьера).

Проверена обязательность всех полей для авторизации.

Проверена обработка негативных сценариев: передача неверного логина/пароля, авторизация под несуществующим пользователем, а также запросы с пропущенными полями.

3. Создание заказа (/api/v1/orders)
С помощью параметризации протестировано создание заказов с различными вариациями параметров цвета (color):

Указание только цвета BLACK.

Указание только цвета GREY.

Указание обоих цветов (BLACK и GREY).

Полное отсутствие указания цвета (пустой массив цветов).

Проверено, что тело успешного ответа обязательно содержит трек заказа (track).

4. Список заказов (/api/v1/orders)
Проверено получение списка всех заказов в системе (тело ответа успешно возвращает массив с заказами).

📊 Отчётность Allure
Для визуализации результатов тестирования настроена генерация детальных отчётов Allure:

К тестам добавлены понятные описания, шаги и группировка по фичам.

Сгенерированные результаты и отчёты подготовлены для публикации в репозитории.

Для запуска тестов с сохранением результатов для Allure выполните команду:
pytest --alluredir=allure-results

Генерация и просмотр Allure-отчёта:
allure serve allure-results
