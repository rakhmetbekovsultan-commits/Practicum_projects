Автотесты UI для сервиса «Яндекс.Самокат»

Проект представляет собой набор автоматизированных UI-тестов для учебного сервиса «Яндекс.Самокат». Тесты написаны на языке Python с использованием библиотеки Selenium WebDriver, паттерна проектирования Page Object Model (POM), параметризации Pytest и генерации отчетов Allure.

📋 Описание проекта
Назначение и цели исследования
Основная цель проекта — автоматизация UI-тестирования ключевых сценариев взаимодействия пользователя с сервисом «Яндекс.Самокат».

Покрытые функциональные сценарии:

Раздел «Вопросы о важном»:

Проверка работы выпадающего списка FAQ на главной странице.

Отдельный тест для каждого вопроса: проверка раскрытия соответствующего текста ответа при клике на стрелочку.

Процесс заказа самоката (Позитивный сценарий):

Проверка двух точек входа в сценарий оформления заказа: кнопка «Заказать» в шапке страницы и кнопка «Заказать» внизу страницы.

Заполнение всех этапов формы заказа с использованием параметризованных наборов данных (минимум 2 набора данных).

Проверка появления всплывающего окна с подтверждением об успешном создании заказа.

Навигация по логотипам:

Проверка клика по логотипу «Самокат»: переход на главную страницу сервиса.

Проверка клика по логотипу «Яндекс»: открытие в новом окне/вкладке главной страницы Дзена через редирект.

Архитектура и структура
Page Object Model (POM): Все локаторы и методы взаимодействия с элементами веб-страниц вынесены в отдельные классы внутри пакета pages.

Разделение тестов: Тесты сгруппированы по функциональности и расположены в директории tests.

Параметризация: Использована параметризация Pytest (@pytest.mark.parametrize) для проверки выпадающего списка FAQ и тестирования формы заказа с различными наборами входных данных.

Стек технологий и библиотеки
Python 3.x

Selenium WebDriver — для управления браузером и автоматизации пользовательских действий.

Pytest — фреймворк для написания, запуска и параметризации тестов.

Allure Pytest — формирование детальных отчетов о прохождении тестов.

Mozilla Firefox / Geckodriver — основной браузер для запуска тестов.

💡 Выводы и результаты
Покрытие автотестами: Реализовано полное покрытие позитивных UI-сценариев заказа и проверки FAQ.

Поддерживаемость кода: Применение паттерна Page Object Model позволяет легко обновлять локаторы и логику взаимодействия при изменениях в интерфейсе без необходимости редактировать сами тесты.

Масштабируемость: Параметризация тестов позволяет быстро добавлять новые тестовые наборы данных без дублирования кода.

Прозрачность результатов: Настроена интеграция с Allure для визуализации результатов прохождения тестов, включая шаги, статусы и ошибки.

Требования и развёртывание
Окружение: Python 3.10+, Firefox, Allure CLI.

Установка:

git clone <url-репозитория> — клонировать проект.

python -m venv venv — создать виртуальное окружение (source venv/bin/activate или venv\Scripts\activate).

pip install -r requirements.txt — установить зависимости (Selenium, Pytest, Allure).

Запуск:

Тесты: pytest --alluredir=allure-results

Отчёт: allure serve allure-results
