# Проект: Автотесты для сервиса «Stellar Burgers»

## Описание
Данный проект содержит набор автоматизированных тестов для веб-сервиса «Stellar Burgers». Тесты реализованы с использованием Python, Selenium WebDriver и Pytest.

Проект покрывает основные сценарии использования:
- Регистрация пользователя.
- Авторизация (различные варианты входа).
- Переходы между разделами «Конструктор» и «Личный кабинет».
- Работа с разделами конструктора (булки, соусы, начинки).
- Выход из аккаунта.

## Технологии
- Python
- Selenium WebDriver
- Pytest

Результаты и выводы
- Все UI-сценарии покрыты автономными тестами (каждый тест запускается в чистом окружении браузера и завершается вызовом `driver.quit()`).
- Поиск элементов реализован через явные ожидания `WebDriverWait` и `expected_conditions`, что обеспечивает стабильность прохождения тестов.
- Для генерации уникальных учётных записей используется динамический генератор e-mail адресов.

## Запуск тестов
Для запуска всех тестов выполните команду в терминале:
pytest -v
